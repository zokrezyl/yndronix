yndronix — Privacy Policy

Last updated: 30 June 2026

yndronix is an Android application that runs a self-contained Linux software environment on your device, and can host an on-device SSH server so you can open a terminal session into your own device over your local network.

Data we collect

yndronix does not collect, store, or transmit any personal data to the developer or to any third party. There is no analytics, no advertising, no user account, and no tracking of any kind.

Data stored on your device

All files, terminal sessions, and the unpacked software environment exist only in the application's private storage on your device. Nothing is uploaded to the developer. This data is removed when you uninstall the app.

Network use

yndronix uses the network only for purposes you initiate:

  • downloading software packages you request into its environment; and
  • hosting an SSH server that you start, which accepts connections you initiate (typically from another device on your own local network).

These connections are between your device and the servers or peers you choose. The developer does not receive, intercept, or have access to any of this traffic.

The on-device SSH server

The SSH server runs only while you have enabled it, and accepts only the credentials (keys or passwords) that you configure. You are responsible for the credentials you set and for who you allow to connect.

Permissions

  • INTERNET — download packages and host the SSH server.
  • FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE — keep the SSH server running while you are using it.
  • POST_NOTIFICATIONS — show the service status notification.
  • WAKE_LOCK — keep sessions alive during use.

Children

yndronix is not directed at children.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a revised "Last updated" date.
